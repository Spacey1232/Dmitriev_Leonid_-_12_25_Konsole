# Конфигурационное управление. Вариант 7

- [Практическая 1: эмулятор оболочки](practice1/step-1/README.md).
- [Практическая 2: граф зависимостей Alpine APK](practice2/README.md).

Python 3.10+. В первой работе нужен Tkinter; дополнительные пакеты Python
для работы программ не требуются. Сборка не требуется.

Запуск первой работы:

```sh
cd practice1/step-1
python3 emulator.py
```

Запуск второй работы из корня репозитория:

```sh
sh practice2/run.sh practice2/examples/a.csv
```

Проверка обеих работ из корня:

```sh
make test
```

Каждый этап каждой работы сохранен отдельным коммитом. Историю можно
посмотреть командой `git log --graph --oneline`.
