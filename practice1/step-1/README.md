# Практическая работа — вариант 7

Нужен Python 3.10+ с Tkinter. Сторонние библиотеки не используются.

Запуск из папки проекта:

```sh
python3 emulator.py
```

Запуск с параметрами из задания:

```sh
python3 emulator.py --vfs examples/deep.xml --script examples/stage4.shell
```

В окне вводите команды и нажимайте Enter. Заголовок использует реальное имя пользователя и имя компьютера. Стартовый скрипт показывает ввод и вывод в этом же окне. Комментарии начинаются с # вне кавычек.

Поддерживаемые режимы команд:

- `ls [путь]` — содержимое каталога или имя файла. Скрытые имена пропускаются, как в обычном ls без флагов.
- `cd [путь]` — переход; без аргумента в виртуальный корень. Поддерживаются абсолютные и относительные пути, . и .. .
- `head [-n N] файл` — первые N строк, по умолчанию 10; N >= 0.
- `tree [путь]` — дерево, по умолчанию от текущего каталога. Скрытые имена пропускаются.
- `rmdir каталог` — удаление одного пустого каталога в памяти. Корень и текущий путь защищены.
- `exit` — закрытие окна.

Флаги и режимы, не перечисленные здесь, не реализованы. Это выбранный учебный набор режимов: в задании флаги команд подробно не определены.

## XML VFS

Корневой элемент — vfs, каталоги — directory с атрибутом name, файлы — file с атрибутом name. Текст хранится непосредственно внутри file. Для двоичных данных используется encoding="base64". Пример — examples/deep.xml. Все данные загружаются в память; исходный XML не изменяется.

## Демонстрация

```sh
sh scripts/config.sh
sh scripts/vfs.sh
sh scripts/demo.sh
```

config.sh проверяет оба параметра и ошибки запуска. vfs.sh запускает три разных VFS. demo.sh показывает все поддержанные режимы основных команд, rmdir и обработку ошибок. Каждая успешная команда запуска открывает отдельное GUI-окно; сценарии завершаются через exit. Отсутствующие пути и другие ошибочные команды в сценариях намеренные.

Для ручной демонстрации запустите без --script и введите:

```text
ls
cd /home/student/docs
head -n 1 "my notes.txt"
cd /
tree
rmdir /empty
ls
rmdir /home
exit
```

После перезапуска каталог empty снова существует, так как изменения были только в памяти.

На первом этапе ls/cd являются заглушками, на третьем VFS загружается, а логика ls/cd появляется на четвёртом. Сценарии stage1 и stage3 отражают команды этих этапов; в финальной версии эти же команды уже работают с VFS.
